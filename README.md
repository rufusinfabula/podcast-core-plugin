# Podcast Core Plugin

Episodes, series and an audio player for podcast websites built with WordPress.
Lightweight, no third-party dependencies. Pairs with [Podcast Core Theme](https://github.com/rufusinfabula/podcast-core-theme).

> Status: early development (0.1.0). Not ready for production.

## Planned features

- `Episode` post type with native meta: number, season, audio URL, duration, video URL
- `Series` taxonomy
- Audio player block
- Platform links (Spotify, Apple Podcasts, YouTube…)
- schema.org `PodcastEpisode` structured data
- Later: import episodes from an existing RSS feed

## Requirements

- WordPress 6.7+
- PHP 8.1+
